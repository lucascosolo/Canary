# Research notes

Raw returns from researcher agents, one file per question. Each file records the question asked,
the date, the agent tier, and the verbatim answer with its evidence list. These notes are the
evidence base for `docs/02-research-landscape.md` and `docs/03-data-source-catalog.md`.

Naming: `<wave>-<nn>-<topic>.md`. Waves: a = democracy and governance indices; b = conflict,
event and news data; c = economic data and early-warning methods from other fields;
d = academic frameworks; e = legislation, elections and human-rights sources; f = technical
options; g = cross-cutting methodology (source reliability, law, calibration, historical analogy).

Notes are never edited after the fact. A correction is a new dated note.
