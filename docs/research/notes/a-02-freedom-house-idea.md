# A-02: Freedom House datasets, International IDEA GSoD indices and Democracy Tracker

- Date: 2026-10-20
- Agent: researcher (Sonnet, low effort), 13 tool uses

## Answer (verbatim)

1. Freedom House (all read 2026-10-20). Freedom in the World (FIW): annual; FIW 2026 is the latest edition. It covers 195 countries and 13 territories (208 total). Data is Excel (xlsx), reached via the Publication Archives (1972 to present) and a data-request link. Freedom on the Net (FOTN): annual, published Oct/Nov (latest FOTN 2025, 13 Nov 2025). It covers 72 countries. There is no direct download; you submit a request through a "Download Data" link. Nations in Transit (NIT): annual in principle, but there was no full 2019 report. The latest is NIT 2024, covering 29 countries. There is a direct Excel file "All Data Nations in Transit NIT 2005-2024". No FIW or FOTN csv, and no API, was found on any page ("not found"). Terms: no data-specific license. Content Permissions page: commercial use "must be formally approved by Freedom House prior to publication". Noncommercial use "is permitted, but the work must be acknowledged with a citation". Sharing already-published online content needs no permission, and US fair use applies. Data files are treated as Freedom House content under the same rules. The FIW page summary says data is free for personal, academic and nonprofit use, while commercial use needs an agreement.

2. IDEA GSoD Indices: 174 countries, many from 1975, updated annually. It has 30 indices scored 0 to 1, from 100+ indicators and 20+ source datasets (V-Dem supplies almost half). Search results say v6 covered 173 countries, v7 covered 174, v9 covered 1975-2024, and v10 (2026) uses 155 indicators. Data and documentation are downloadable from the GSoD Indices interactive site, but file formats are not stated ("not found"). The IDEA pages do not name an API ("not found"). The license is NOT verified: no page I could read states CC BY-NC-SA or any other license. The contact is GSoD.indices@idea.int. The framework groups the indices into four categories: Representation, Rights, Rule of Law, Participation. The old "five attributes" wording was not confirmed.

3. Democracy Tracker: monthly analyses of democracy-related events, each report on one event in one country. It monitors 173 countries against 29 indices. Entries are produced from local and primary sources, Nexis Newsdesk (100,000+ outlets) and GDELT. Report types are Standard (impact coded from exceptionally positive to exceptionally negative), To Watch, National Election, and Red Flag. Methodology is being adapted during 2026, with complete coverage expected by end of 2026. Download, API and RSS are not mentioned ("not found"). Terms are only linked as a site Terms and Conditions page, which I did not read.
